LESSON 02

HTML, CSS & JavaScript

网页三件套

Every web page is made of three layers. Each one has its own job and usually its own file.

每个网页都由三层组成。每一层负责一件事，通常也各有一个文件。

LayerJobLike in FigmaFile
HTMLContent and structure
内容和结构		Layers and textindex.html
CSSHow it looks
外观		Fills, fonts, Auto Layoutstyle.css
JavaScriptHow it behaves
行为、交互		Prototype interactionsscript.js

Front-end vs back-end

前端和后端

Front-end is everything users see and touch in the browser. Back-end runs on a server and handles data like accounts, orders, and databases. Designers usually start with front-end.

前端是用户在浏览器里看到、点到的一切。后端运行在服务器上，处理账号、订单、数据库等数据。设计师通常从前端入手。

Try it: turn the layers on and off

动手试试：打开和关闭每一层

Daily UI #001

A sign-up card for a music app.

Without CSS, the page still works, but it looks like a raw wireframe. Without JavaScript, it looks fine, but the button does nothing.

没有 CSS，页面还能用，但像一个原始线框图。没有 JavaScript，页面好看，但按钮点了没反应。
