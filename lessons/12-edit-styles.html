LESSON 12 · PART 3

Edit styles live

实时修改样式

In the Styles pane you can change any CSS and see the result instantly. It's the fastest way to try "what if the padding were 4px bigger?" on a real page, without asking a developer.

在 Styles 面板里，你可以修改任何 CSS 并立刻看到效果。想在真实页面上试试"内边距再大 4px 会怎样"，这是最快的方法，不用麻烦开发。

What you wantHow
Change a value
改数值		Click the value and type. Use ↑ / ↓ to step by 1, Shift + ↑ / ↓ by 10
Turn a property off
关掉某个属性		Hover the line and uncheck its checkbox
Pick a color
选颜色		Click the small color square. The picker has an eyedropper and shows the contrast ratio for text
See hover or focus styles
查看悬停、聚焦样式		Click :hov and check :hover, :focus, etc.
Try a class
试加一个类名		Click .cls and type a class name
See everything you changed
查看所有改动		Cmd + Shift + P → type Show Changes

Edits only live in your browser. Refreshing the page erases them, so copy your changes before you reload. Right-click a rule → Copy all declarations is handy for sending to developers.

修改只存在于你的浏览器里，刷新页面就会消失，所以刷新前先复制。右键规则 → Copy all declarations，很方便发给开发。
