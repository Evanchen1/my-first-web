LESSON 14 · PART 3

Design QA toolkit

设计走查工具箱

When a page is built, DevTools helps you check it the way a designer would: colors for every user, dark mode, real fonts, and consistency. Most of these live in the Rendering tab: press Cmd + Shift + P and type Show Rendering.

页面做好后，开发者工具可以帮你用设计师的眼光检查：每个用户看到的颜色、深色模式、真实字体，以及一致性。大部分功能在 Rendering 标签页里：按 Cmd + Shift + P，输入 Show Rendering。

Tool 1: Emulate vision deficiencies

工具 1：模拟色觉障碍

About 1 in 12 men has some kind of color vision deficiency. In Rendering, find Emulate vision deficiencies. Try it here: can you still tell "Error" from "Success"?

大约每 12 个男性中就有 1 个有某种色觉障碍。在 Rendering 里找到 Emulate vision deficiencies。在这里试试：你还能分清 "Error" 和 "Success" 吗？

Order status

Colors only, no icons or text hints.

Success Error Warning Info

Lesson: never use color as the only signal. Add an icon, a label, or a pattern too. These filters are approximations, and DevTools' version is more accurate.

结论：不要只靠颜色传达信息，同时加上图标、文字或图案。这里的滤镜是近似效果，开发者工具里的更准确。

Tool 2: Emulate dark mode

工具 2：模拟深色模式

In Rendering, set Emulate CSS media feature prefers-color-scheme to dark. Pages that support dark mode switch instantly, without changing your Mac's settings.

在 Rendering 里，把 Emulate CSS media feature prefers-color-scheme 设为 dark。支持深色模式的页面会立刻切换，不用改 Mac 的系统设置。

Tool 4: Edit text right on the page

工具 4：直接在页面上改文字

Want to test a longer title or a German translation? Open the Console tab and run document.designMode = "on". Now you can click any text on the page and type, like a text layer in Figma. Refresh to undo.

想测试更长的标题，或者德语翻译？打开 Console 标签页，运行 document.designMode = "on"。然后就能点击页面上任何文字直接输入，就像 Figma 的文字图层。刷新即可还原。

One more: which font is really used?

还有一个：实际用的是哪个字体？

CSS lists fonts in order, like font-family: "Inter", "PingFang SC", sans-serif. If the first one fails to load, the browser quietly uses the next. Select an element, open Computed, and scroll to the bottom: Rendered Fonts shows the font actually drawn on screen.

CSS 会按顺序列出字体。如果第一个没加载成功，浏览器会悄悄换用下一个。选中元素，打开 Computed，滚到最底部：Rendered Fonts 显示屏幕上真正使用的字体。
