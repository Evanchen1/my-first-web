Figma 右侧面板里的大多数属性，在 CSS 里都有对应的写法。记住名字后，读 CSS 就会很亲切。

Shortcut: browser DevTools

捷径：浏览器开发者工具

On any website, right-click and choose Inspect, or press Cmd + Option + I. You can see the CSS of every element and change it live. Changes only affect your screen, so it's safe to play.

在任何网站上右键选"检查"，或按 Cmd + Option + I。你能看到每个元素的 CSS，还能实时修改。修改只影响你自己的屏幕，可以放心玩。
