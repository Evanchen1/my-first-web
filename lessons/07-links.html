LESSON 07

Links and multiple pages

链接与多页面

To jump to another page, use the <a> tag. It works like a Figma prototype connection: On click → Navigate to.

跳转到另一个页面要用 <a> 标签。它就像 Figma 原型里的连线："点击时 → 跳转到"。

<a href="about.html">About →</a>
  • a stands for "anchor" a 是 anchor（锚点）的缩写
  • href says where to go href 表示要跳转到哪里
  • The text between the tags is what people click 标签中间的文字就是用户点击的内容
TypeExampleResult
Your own pagehref="about.html"Opens in the same tab
在当前标签页打开
Another websitehref="https://..." target="_blank"Opens in a new tab
在新标签页打开

Try it: click around a tiny website

动手试试：在一个迷你网站里点一点

Click a link to see its code.

Paths: how files find each other

路径：文件之间怎么找到对方

This website keeps lessons in a lessons folder. So links need to know where they are starting from.

这个网站把课时放在 lessons 文件夹里，所以链接需要知道自己从哪里出发。

my-first-web/
├── index.html         ← home page
├── style.css
└── lessons/
    ├── 06-responsive.html
    └── 07-links.html  ← you are here
  • Next lesson, same folder: href="08-javascript.html" 下一课在同一个文件夹，直接写文件名
  • Home page, one folder up: href="../index.html". The ../ means "go up one folder". 首页在上一层文件夹，../ 的意思是"往上走一层"
