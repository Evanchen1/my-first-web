LESSON 03

Class: linking HTML and CSS

类名：连接 HTML 和 CSS

How the connection works

它们是怎么连起来的

  1. HTML gives an element a name tag: <div class="card"> HTML 给元素贴一个名字标签
  2. The page loads the CSS file: <link rel="stylesheet" href="style.css"> 页面加载 CSS 文件
  3. CSS finds every element with that name and styles it: .card { ... } CSS 找到所有叫这个名字的元素，给它们加样式

The dot in .card means "every element whose class is card".

.card 里的"点"表示"所有 class 是 card 的元素"。

It's like a shared style in Figma. Define it once, use it everywhere, and change it in one place.

这就像 Figma 里的共享样式：定义一次，到处使用，改一处全部更新。

Try it: one rule, many cards

动手试试：一条规则，控制多张卡片

Uncheck a box to remove class="card" from that element.
取消勾选，就会去掉那个元素的类名。
