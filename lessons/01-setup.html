Your first page in 5 steps

5 步做出第一个网页

  1. Create a folder, then open it in VS Code with Open… 新建一个文件夹，在 VS Code 里用 Open… 打开
  2. Create a file named index.html. The .html ending matters. 新建 index.html 文件，.html 后缀很重要
  3. Type !, wait for the popup, and press Tab to get the HTML skeleton. 输入 !，等弹出菜单出现后按 Tab，生成 HTML 骨架
  4. Write <h1>Hello</h1> inside <body>. 在 <body> 里写一个标题
  5. Click Go Live in the bottom-right corner. It turns into Port : 5500 while running. 点右下角的 Go Live，运行时会变成 Port : 5500

127.0.0.1:5500 means "this computer, door number 5500". Only you can see it until you publish.

127.0.0.1:5500 的意思是"本机的 5500 号门"。发布之前只有你自己能看到。

Try it: the edit → save → see loop

动手试试："修改 → 保存 → 查看"循环

Edit the code, then press Save. Turn Live Server off to feel the difference.

修改代码，然后点 Save。关掉 Live Server，感受一下区别。
