JavaScript interactions

JavaScript 交互

Almost every interaction follows the same 3 steps: find an element, listen for an event, then change something.

几乎所有交互都是同样的 3 步：找到元素，监听事件，然后改变某些东西。

// 1. Find the button (找到按钮)
const button = document.getElementById("theme-button");

// 2. Listen for a click (监听点击)
button.addEventListener("click", function () {

    // 3. Change something: add or remove the "dark" class (改变：加上或去掉 dark 类名)
    card.classList.toggle("dark");
});

Notice that JavaScript rarely changes colors directly. It adds or removes a class, and CSS decides how that class looks. Like switching a variant in Figma.

注意：JavaScript 很少直接改颜色。它只是加上或去掉一个类名，长什么样由 CSS 决定。就像在 Figma 里切换组件变体。
