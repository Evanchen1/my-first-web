LESSON 11 · PART 3

Inspect any element

检查任意元素

Chrome DevTools is a set of tools built into the browser. For designers, it's like Figma's Dev Mode, but for any live website: you can see the size, spacing, colors, and fonts of anything on screen.

Chrome 开发者工具是浏览器自带的一套工具。对设计师来说，它就像"可以用在任何网站上的 Figma Dev Mode"：屏幕上任何东西的尺寸、间距、颜色和字体都能看到。

ActionMac shortcut
Open DevTools
打开开发者工具		Cmd + Option + I
Pick an element on the page
在页面上选取元素		Cmd + Shift + C
Inspect one thing directly
直接检查某个东西		Right-click it → Inspect

The Elements panel

元素面板

  • DOM tree (left): the HTML of the page, like the Layers panel in Figma DOM 树（左边）：页面的 HTML，就像 Figma 的图层面板
  • Styles (right): the CSS rules for the selected element. Lesson 12 covers editing them Styles（右边）：选中元素的 CSS 规则，第 12 课会讲怎么修改
  • Computed: the final values after all rules are combined, plus the box model diagram Computed：所有规则合并后的最终数值，还有盒模型图

The highlight colors always mean the same thing: blue = content, green = padding, yellow = border, orange = margin.

高亮颜色的含义永远一样：蓝色是内容，绿色是内边距，黄色是边框，橙色是外边距。
