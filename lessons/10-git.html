LESSON 10

Git, GitHub & updates

Git、GitHub 与迭代更新

Git is not GitHub

Git 不等于 GitHub

What it isWhere it livesLike
GitA tool that saves versions of your code
保存代码版本的工具		Your computer. No app icon, it runs from the terminal or VS Code
你的电脑上，没有图标		Figma version history

在线存放 Git 项目的网站		github.comFigma cloud files

把仓库变成网站		you.github.ioPublishing a prototype

First-time setup (done once)

第一次设置（只做一次）

  1. git init: turn the folder into a Git repository 把文件夹变成 Git 仓库
  2. Add a .gitignore file to list files that should never be uploaded 添加 .gitignore，列出永远不上传的文件
  3. Set your author name and email. In a public repository, the email is visible 设置作者名字和邮箱。公开仓库里邮箱会被看到
  4. In VS Code Source Control, click Publish Branch and sign in to GitHub 在 VS Code 源代码管理里点 Publish Branch，登录 GitHub
  5. Make the repository public: Settings → General → Danger Zone → Change visibility 把仓库改成公开
  6. Settings → Pages → Deploy from a branch → main + / (root) → Save 在 Pages 设置里选择分支并保存

Every update after that

之后每次更新

  1. Edit and save your files. Check with Go Live. 修改并保存文件，用 Go Live 检查
  2. Commit: write a short note and save a version. Only on your computer. 提交：写一句说明，保存一个版本。只在你电脑上
  3. Sync: upload to GitHub. The site rebuilds in 1–2 minutes. 同步：上传到 GitHub，网站 1 到 2 分钟内重新生成

Try it: edit → commit → sync

动手试试：修改 → 提交 → 同步

你的文件

    3. GitHub + live site

    GitHub 和线上网站

      Commit as often as you like, since it's free and local. Only Sync triggers a build, and GitHub Pages allows about 10 builds per hour (soft limit), no matter how small the site is. So commit often, sync in batches.

      commit 可以随便提交，因为它是免费的、本地的。只有 Sync 会触发生成，GitHub Pages 每小时大约允许 10 次（软上限），和网站大小无关。所以多 commit，攒一批再同步。
