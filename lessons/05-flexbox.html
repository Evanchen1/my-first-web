LESSON 05

Flexbox = Auto Layout

Flexbox 就是 Auto Layout

Flexbox is the CSS version of Auto Layout. It's the layout tool you'll use most.

Flexbox 就是 CSS 版的 Auto Layout，是你最常用的布局工具。

Auto LayoutFlexbox
Turn on Auto Layoutdisplay: flex
Direction (→ / ↓)flex-direction: row / column
Alignment, along the directionjustify-content
Alignment, across the directionalign-items
Spacing between itemsgap
Space between (Auto)justify-content: space-between
Fill containerflex: 1 (on the child)
Wrapflex-wrap: wrap
