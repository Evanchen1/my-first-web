LESSON 06

Responsive design

响应式设计

One web page has to fit every screen: phone, tablet, and desktop. In Figma you draw a frame for each breakpoint. In CSS you write media queries that switch styles at certain widths.

一个网页要适配所有屏幕：手机、平板、电脑。在 Figma 里你为每个断点画一个 Frame；在 CSS 里你写"媒体查询"，在特定宽度切换样式。

.cards {
    display: flex;
    flex-direction: row;       /* Desktop: side by side */
}

@media (max-width: 600px) {    /* Screens narrower than 600px */
    .cards {
        flex-direction: column; /* Phone: stacked */
    }
}

Units: px, %, and rem

单位：px、% 和 rem

  • px: fixed pixels, same as in Figma 固定像素，和 Figma 一样
  • %: relative to the parent element, so it stretches 相对于父元素，会跟着伸缩
  • rem: relative to the base font size, usually 16px. If a user makes their text bigger, rem sizes grow too 相对于基础字号（通常是 16px）。用户把文字调大时，rem 尺寸也会一起变大
